# AutoBudgetin v28.3.0 — Clean Finance Hub

## Fokus
- UI v28 dibuat lebih elegan, flat, dan konsisten dengan Lucide icons.
- Shortcut Information baru di web untuk membuka fitur utama tanpa memenuhi bottom navigation.
- Telegram Shortcut Center dirapikan menjadi tombol minimal dan tidak bergantung pada mengetik /menu.
- Auto Budget memiliki mode Otomatis dan Manual.

## Auto Budget
### Otomatis
1. Tentukan pendapatan (atau kosongkan untuk memakai transaksi Gaji bulan berjalan).
2. Tentukan target tabungan nominal.
3. Sisa pendapatan dibagi otomatis ke delapan bucket kebutuhan.
4. Proporsi bisa diubah di Advanced tanpa kehilangan mode otomatis.

### Manual
Pendapatan dan target tabungan tetap dihitung, tetapi limit setiap bucket diisi sendiri.

## Responsiveness
- Desktop: grid padat dua/empat kolom sesuai konteks.
- Mobile: card, modal, shortcut, review, dan pengaturan budget turun menjadi 1–2 kolom tanpa horizontal overflow.

## Telegram
Shortcut: Ringkasan, Hari ini, Pemakaian, Budget, Tabungan, Durasi, Terbesar, Refresh, serta seluruh bucket pengeluaran.
