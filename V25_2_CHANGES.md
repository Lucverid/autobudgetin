# v25.2 — Clean Home

- Smart Insight card removed from Home because its information overlaps with status, score, projection, weekly review, anomaly alerts, and planning tools.
- Smart Insight calculation code is intentionally retained for compatibility and existing calculations/notifications.
- Financial Score is now a compact “Kondisi Keuangan” indicator instead of a large dashboard card.
- Essential vs Non-essential details remain available through the existing finance controls/reports rather than occupying Home space.
- Mobile Home is less crowded while all v25.1 features, offline mode, backup, Google Sheets sync, and Telegram automation remain intact.
