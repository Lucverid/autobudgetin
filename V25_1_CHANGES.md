# Agis Finance v25.1 — Mobile Focus

- Tema visual v25 dipertahankan; kepadatan UI HP dikurangi.
- Home HP punya mode **Ringkas / Lengkap**. Mode Ringkas menyembunyikan Cashflow detail, Smart Insight, chart, dan Yearly Report; data/fungsinya tetap ada dan bisa dibuka dengan mode Lengkap.
- Wallet di HP menjadi horizontal swipe cards agar tidak sesak.
- Budget Planning + Bill Calendar menjadi horizontal snap cards pada HP.
- Budget Planning diberi label **Target Alokasi** dan Limit Bulanan diberi label **Pagar Maksimum** agar tidak terasa duplikat.
- Settings mobile dipadatkan tanpa menghapus fitur.
- Cache PWA naik ke `agis-finance-v25-1`.
